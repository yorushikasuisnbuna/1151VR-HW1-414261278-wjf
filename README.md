我這裡在Unity引擎中進行 3D 場景編輯與物件操作的過程，主要製作流程與相關操作步驟如下：

新增 3D 物件操作者在左側 Hierarchy視窗中點擊右鍵或 + 號選單，選擇 3D Object -> Cube，在場景中建立了一個方塊物件。   

調整物件位置與變形工具使用工具列上的 Move Tool動工拖曳箭頭，將 Cube 移動到直升機模型的旁邊。   

切換至 Rotate Tool或 Scale Tool，並在右側 Inspector視窗中的Transform組件修改參數。   影片中手動調整了縮放數值，將方塊放大。   

場景視角瀏覽與調整，在Scene視窗中利用滑鼠及alt達成自由旋轉與移動調整視點，從不同角度觀察直升機與方塊的相對位置。   

切換至 Game 視窗與測試運行最後點擊上方中央的Play按鈕，切換至Game視窗預覽Main Camera實際看到的遊戲畫面。

還有更改版面配置和引入免費的3D素材並利用素材檔裡的texture給模型外觀上色
